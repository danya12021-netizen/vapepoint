# VapePoint Telegram Mini App

Информационный демонстрационный интерфейс на React + Vite. В этой версии нет каталога никотиновой продукции, корзины, оформления заказов или платежей.

## Запуск и сборка

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
npm run build
```

Для публикации загрузите содержимое проекта в репозиторий GitHub и подключите репозиторий к статическому хостингу (например, Vercel или Netlify). Команда сборки: `npm run build`; папка результата: `dist`.

## Telegram

После публикации сайта по HTTPS укажите домен Mini App в настройках бота через BotFather. На сервере обязательно проверяйте подпись `Telegram.WebApp.initData`; не доверяйте `initDataUnsafe` как доказательству личности.
